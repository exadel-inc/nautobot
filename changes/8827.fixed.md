Tightened `IPAddress.dns_name` validation to enforce RFC 952/1123 hostname rules instead of just checking allowed characters: labels must not start or end with a hyphen or be empty, each label is at most 63 characters, and the overall name is at most 253 characters (plus an optional trailing root dot). As part of this change, underscores (`_`) are no longer accepted anywhere in `dns_name`, which is an intentional compatibility change from prior releases. Existing records with a `dns_name` that does not comply with these stricter rules are not modified or migrated, but will need to be corrected the next time the record is edited and saved.
